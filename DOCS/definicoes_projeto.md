# Descrição do projeto
Nesse documento será descrito como o projeto foi pensado e como ele será desenvolvido.

## Motivação
O projeto foi pensado inicialmente de seguir padrões de aplicativos de cofre de senha, como Passwords(Apple), bitwarden etc. O cofre de senha irá funcionar com um cadastro inicial, onde será necessário informar email e uma **senha master**. Essa senha master será a responsável por permitir acesso ao cofre do usuário, acesso a revelar senhas entre outras funcionalidades.
